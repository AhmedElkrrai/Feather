# Store graphics

Made from the owl's layers (`app/src/main/res/drawable-nodpi/owl_*.png`), on the same pale sky as the
launch screen. The sources are in `art/`.

| File | Size | Used for |
|---|---|---|
| `icon.png` | 512 x 512 | Google Play app icon (32-bit PNG, no rounded corners: the store rounds it) |
| `feature-graphic.png` | 1024 x 500 | Google Play feature graphic (no transparency) |

The title is set in Young Serif and the lines under it in Nunito, the app's own fonts. An Arabic version
needs its own text (right-to-left) and is not made yet.

Screenshots are taken from the running app (see `store/STORE.md`).
